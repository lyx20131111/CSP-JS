## 🎯 功能特点

| 功能 | 说明 |
|:---|:---|
| ✅ **智能判卷** | 提交后自动对答案，显示正确/错误和正确率 |
| ✅ **只看错题** | 一键筛选，只显示做错的题，精准复习 |
| ✅ **详细解析** | 每道题都有完整解析，点击即可查看 |
| ✅ **按年刷题** | 支持按年份（2021–2025）切换，针对性练习 |
| ✅ **难题专项** | 独立「难题集」板块，挑战高难度 |
| ✅ **进度保留** | 切换题库不丢失已选答案（刷新会重置） |
| ✅ **纯前端** | 无需服务器，浏览器直接运行，隐私安全 |
